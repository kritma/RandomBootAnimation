# Random Boot Animation
1. Install via [Magisk](https://github.com/topjohnwu/Magisk)
2. Put [animations](https://android.googlesource.com/platform/frameworks/base/+/master/cmds/bootanimation/FORMAT.md) in ```/data/local/bootanimations/``` ([File Manager](https://github.com/zhanghai/MaterialFiles))
3. reboot
4. enjoy
